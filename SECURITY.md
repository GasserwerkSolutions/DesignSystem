# Security Policy

## Supported versions

Security fixes are applied to the latest tagged release. Builder integrations
must pin an exact release tag and SHA-256 instead of consuming a moving branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting flow in the repository's
**Security** tab. Do not publish credentials, exploit details or customer data
in a public issue.

Include the affected version, a minimal reproduction and the expected impact.
The report will be acknowledged and assessed before public disclosure.
